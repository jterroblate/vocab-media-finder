# 统一版宿主自适配

让用户只交词表或文章，并选择视频、歌曲或两者。只导入 `vocab-media-finder` 一个技能；视频与音乐是包内模块，不再要求另一技能安装路径。

1. 定位本 SKILL.md 目录及 `run.py`，检测实际 Python 3.10+、文件读写、搜索、正文抓取和客户端观察能力。有缺项时如实缩小范围，不把无工具聊天窗口说成可自动执行。
2. 先运行 `run.py demo --output <工作区新目录>`，验证离线流程；不读账号、不联网、不提供真实推荐。源码和安装包布局由程序自动识别，不依赖作者电脑目录。
3. 将用户词表/文章提取为 JSON，提出并复核词族关系。先尝试可用本地词典，缺资源时显式补 `forms/related`，不要求新的字幕/音乐 API Key，不把同义词计目标命中。
4. 用 `run.py plan` 生成待办，再使用宿主真实搜索工具执行；`video` 和 `music` 都从同一 `run.py` 调用。视频内部工作流中的 VVF 映射为 video/ 引擎根。视频单独任务不得读音乐账号。
5. 音乐任务先自动检查支持的本机客户端；身份不明时由现有应用工具核对当前账号，不向新手索内部 ID。缺登录可打开官方客户端，请用户正常登录/同步；未知 schema、加密缓存、Windows 本地限制和 QQ 原生未测范围保持原样，不冒充已取得偏好。
6. 核对正文、语境、版本、可达性和难度，区分实际播放检查范围。歌手扩展不等于已喜欢；同一录音多平台入口去重。真实数据留在调用工作区，不输出完整歌词，不发送或调度。

WorkBuddy 直接导入对应的单 ZIP；DeepSeek Harness 按其当前约定把唯一技能目录放入项目技能根。宿主原生运行未验证时明确说明，包测试不能替代原生验证。新用户无需管理两个技能或处理路径、Key和账号数字。
