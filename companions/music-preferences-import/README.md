# music-preferences-import

[English](README.en.md) · `0.3.0-experimental` · Python 3.10+ · MIT

这是 `vocab-video-finder` 的可选音乐组件。从本机网易云音乐或 QQ 音乐可读取的数据中提取偏好线索，再按词族寻找英文歌曲。视频和音乐组件可以分别使用；发送与定时投递由独立组件负责。

## 默认使用方式

用户只需说：

> 按我的网易云/QQ音乐偏好，找含这些词的英文歌。

Agent 先检查本机官方客户端、当前账号和可用缓存，不先要求用户提供分享链接、数字 ID、密码、Cookie 或音乐 API Key。`--provider auto` 分别检查两个平台，隔离平台 ID；一个客户端不可用不阻塞另一个。

缺少客户端、登录或同步数据时，由 Agent 打开官方客户端，让用户按平常方式登录并等待同步。当前不提供自动扫码登录，不绕过加密数据库，不保证读取私密历史、所有设备记录或精确播放次数。

## 当前支持范围

| 能力 | 网易云音乐 | QQ 音乐 |
|---|---|---|
| macOS 自动发现缓存 | 已在 3.1.12 客户端实测 | 已实现，原生客户端未实测 |
| 本地红心 | 识别账号与歌单，API 补资料 | 仅明确歌单关联的 schema；未知映射不猜 |
| 本机近期 | 近 30 天去重历史，不等于频次 | 近期 schema 未验证，返回不可用 |
| 公开 API | 歌单、歌曲资料、歌手作品、歌词已实测 | 歌单分页、歌曲详情、歌手 MID 作品、普通 LRC 已实测 |
| Windows 本地读取 | 尚不支持 | 尚不支持 |

多账号缓存由 Agent 核对当前客户端身份，不能选数据库第一条。QQ 不按相同歌数猜红心分组；未知 schema 或不可读数据库保留 `unavailable/ambiguous`。缓存不是 API 已登录的证明；未确认授权时的空近期响应标为 `auth_unknown`，不能写成用户没听歌。

## 匹配与复核

先用红心和近期线索找歌手，再从取得英文文本证据的偏好歌曲扩展同歌手作品。新作品不继承红心状态。标题仅作召回线索，中文标题也能入围；标题出现目标词不计命中。

Agent 先复核词族，将确认的原词、屈折和派生成员写入工作区词表 JSON；用户无需自己补词形。组件复用视频核心匹配时态、三单、分词、不规则形式及确认派生。纯字符串词表只做所列形式匹配，不假装完成扩词；脚本默认词表仅用于通用试验。

次数针对取得的歌词正文。语言、完整录音版本、语境、听辨难度与播放状态仍须逐首复核；试算默认 `ready_to_deliver=false`，不等于可投递清单，不导出完整歌词。

## 在另一台电脑试用

下载 [music-v0.3.0 发布包](https://github.com/jterroblate/vocab-video-finder/releases/tag/music-v0.3.0)。独立音乐包自带匹配核心，不依赖本机路径；组合包包含两个顶层技能目录。

- Codex：将对应技能目录放进当前用户的技能目录，保留两个组件各自的 `SKILL.md`。
- WorkBuddy：导入独立 `music` ZIP；组合 ZIP 不是单个技能包，要将两个技能分别导入。
- WorkBuddy 入门包（starter）内含两个独立 ZIP，解压后分别导入即可，不需要重新打包。
- DeepSeek Harness：按宿主实际约定，将两个技能分别放入 `.dsh/skills/` 或 `.agents/skills/`；先执行包内[自适配提示词](adapters/bootstrap.md)，不假定 Codex 配置会自动加载。

WorkBuddy、DeepSeek 音乐原生运行尚未实测；包结构和降级契约测试不能替代原生验证。

无需客户端、账号或网络的合成演示适合录屏：

```sh
python3 demo.py --output demo-output
```

真实查找由 Agent 在音乐技能目录内执行，词表由 Agent 整理：

```sh
python3 run_music_trial.py --provider auto --words '<工作区词表.json>' --output '<工作区新目录>'
```

`--words` 支持视频核心的 `word/forms/related` JSON 格式。省略时使用通用测试词表。核心会自动从相邻视频技能、包内 `core/` 或源码仓库定位。`--verified-nickname/--verified-qq-account` 由 Agent 观察后填写，不向用户索取 ID。

## 数据边界

仓库、ZIP 和离线演示只含通用代码、说明与合成数据，不包含个人歌单、客户端数据库、凭据、歌词全文或本机试验输出。真实偏好与复核结果留在调用工作区。接口是平台内部公开 HTTP 入口，没有长期稳定承诺；失败会保留状态，不伪造零命中。
