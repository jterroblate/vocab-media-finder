# 宿主自适配

让用户只描述目标：按自己的网易云或 QQ 音乐偏好，找包含词表的英文歌曲。其余由宿主处理。

1. 定位本 SKILL.md 目录、Python 3.10+ 与实际工具能力。音乐包内带标准库匹配核心；源码检出可定位仓库 scripts/。不要求额外音乐 API Key。
2. 检查当前操作系统与客户端。自动读本机支持的只读缓存；账号不明确时，由已有应用控制工具核对当前身份。没有此工具则保留歧义，不要求新手查内部账号 ID。
3. 缺登录或缓存时，宿主可打开官方客户端，请用户正常登录/同步。QQ 未知 schema、私密数据、Windows 本地读取的限制按 README 如实呈现；不解密、不读凭据，不称为完整历史。
4. 词表/文章由宿主提取为 JSON，并复核目标词的 forms/related。可配合视频 skill 的词族扩展；资源缺失时由宿主提出并复核，不将普通同义词算命中。
5. 先运行 `python3 demo.py --output <工作区新目录>` 检查脚本，再按 README 运行真实查找。路径和参数由宿主填，用户不需要操作命令行或提供分享链接。
6. 完整歌词仅内存处理，输出词频摘要和来源。真实数据只留当前工作区；复核正文、版本、词义、语言、听辨和播放后才整理候选。发送与调度另由独立组件负责。

WorkBuddy 使用独立 music ZIP 导入；pair ZIP 含两个技能，不能作为单一技能上传。DeepSeek Harness 与其他 Agent 先按实际技能目录约定加载本 SKILL.md，不能假定 Codex 配置会自动生效。未实测原生环境时明确说明，不能将包测试说成原生验证。
